# Coding Standards

## Special Characters Rule

Do not allow special characters in variable names, function names, class names, or identifiers. Only use:
- Alphanumeric characters (A-Z, a-z, 0-9)
- Underscores (_)
- Camel case or snake case naming conventions

Special characters such as @, #, $, %, &, *, etc. should not be used in code identifiers.
