# Colorful Username Skill

This skill displays your username with beautiful multi-colored bubbles.

## What This Skill Does

When you type "show-me-colors", I will:
1. Get your system username
2. Display it with colorful ASCII art bubbles
3. Show a rainbow color palette

## Workflow

1. Run the [colorful-display script](./scripts/colorful-username-display.js)
2. Display username with colored bubbles
3. Show color palette demo
